MONICA SALVIOLI — PERSONAL ACADEMIC WEBSITE

FILES TO UPLOAD TO THE ROOT OF YOUR GITHUB REPOSITORY:
index.html
research.html
team.html
publications.html
teaching.html
style.css

Upload to: https://github.com/monicasalvioli/monicasalvioli.github.io
1. Open the repository (Code tab).
2. Select Add file > Upload files (or the + menu > Upload files).
3. Extract the ZIP on your computer, then select ALL SIX website files and drag them onto GitHub's upload area. Do not upload the ZIP itself.
4. Commit changes to main.
5. Wait for GitHub Pages to publish and open https://monicasalvioli.github.io/

There are no build tools or dependencies. Edit each .html file on GitHub with the pencil button to customize text. Replace the portrait placeholder in index.html when you have a picture.
